ClosedVPS
Guide GitHub

A Hetzner server with every port closed.

ClosedVPS buys it from your own computer. When Hetzner is sold out, it checks every minute and buys the first server on your list that comes into stock, up to the price you set. You get in over Tailscale.

$ curl -fsSL https://closedvps.com/install.sh | sh
$ closedvps create
PS> irm https://closedvps.com/install.ps1 | iex
PS> closedvps create

Open source, MIT · macOS, Linux and Windows · Runs on your computer, no ClosedVPS account · Your Hetzner token only goes to Hetzner's API

When Hetzner is sold out

Since June 2026 Hetzner often shows its cheaper types as unavailable, and it refuses new servers on new accounts and on some older ones chosen at random (a write-up of what changed). ClosedVPS takes any refusal that waiting can fix as another round. One it can't fix, such as a bad token or a full account limit, stops it with Hetzner's own message. While it waits it keeps your computer from sleeping on idle, but closing a laptop lid still stops it.

Your computer shows a notification when it buys a server, when the server answers SSH over your tailnet, and if it stops without buying. Give it an ntfy, Discord, Slack or Telegram link, or any webhook, and the alerts go there too; the "ready" one comes from the new server itself. For waits longer than a laptop stays open, run it on any machine that stays on, in Docker if you like.

What you get

Hetzner firewall
No inbound rules, attached in the same API call that creates the server, so it never boots open. If another firewall in your project lets traffic in, ClosedVPS warns you, and closedvps list checks again any time.
SSH over Tailscale
Key login only, for one user named after your account on this computer. Root can't log in.
Security updates
Installed daily, with a reboot at 04:00 UTC when one needs it.
Several at once
--count 10 buys ten as stock appears. A cap per server type and one for all your servers together keep the bill where you set it.
Backups
Hetzner keeps 7 daily copies for 20% of the server price. On unless you turn them off.
Cloudflare Tunnel
Runs your tunnel when you pass CLOUDFLARE_TUNNEL_TOKEN, for sites you want public.
Docker
If you install it later, ports you publish bind to 127.0.0.1. To reach one from your laptop, publish it on the server's Tailscale IP (-p 100.x.y.z:3000:3000).
Claude Code
With --claude. You log in to your own account.

You need a Hetzner API token with Read & Write, a Tailscale auth key and an SSH key on this computer. The first run asks for the token and offers to keep it in your system's password store. Then it asks where and what to buy, your price caps, backups, your user name and where alerts go, and remembers the answers. The Tailscale key is asked for on every run and never saved.

closedvps create --dry-run prints the whole first-boot setup before you pay for anything. To get rid of a server, delete it and its closedvps-vps firewall in the Hetzner Console, and remove it from your Tailscale admin.

If Tailscale stops working

closedvps open-ssh vps opens port 22 to your current IPv4 address, so you can SSH to the server's public IP and fix Tailscale. closedvps close-ssh vps shuts it again.
