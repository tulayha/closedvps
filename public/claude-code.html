Claude Code on a Hetzner VPS, with every port closed

On a VPS, Claude Code keeps working while your laptop sleeps, and you can pick the session up from your phone. It also runs the code it writes, starts dev servers and installs packages, so the server it runs on should have nothing reachable from the internet. ClosedVPS buys that server with one command.

Pick a server

Claude Code asks for 4 GB of RAM or more, on x64 or ARM. On Hetzner that's a CX23 (2 cores, 4 GB, 5.99 EUR a month with IPv4, before VAT, in November 2026) or the ARM CAX11 for 6.49 EUR. Both are often sold out, and what to do when Hetzner is sold out covers that.

Create it with Claude Code on it

closedvps create --type cx23,cax11 --claude

It buys the first of those two that's in stock, behind a Hetzner firewall with no inbound rules, and the server joins your tailnet on its first boot. You get a user named after your account on your computer, with your SSH key, and Claude Code installed for that user. Ubuntu 24.04 blocks the user namespaces that Claude Code's sandbox (bubblewrap) needs, so it also adds an AppArmor profile that lets bubblewrap use them.

Log in to Claude

ssh dev@vps
claude

Claude Code prints a link. Open it in your laptop's browser, sign in, and paste the code back into the terminal if it asks for one.

Carry on from your phone

tmux new -s claude
claude remote-control

Remote Control only makes outbound HTTPS requests, so it works with every port closed. In the Claude app, tap Code and pick the session. tmux keeps it running after you close SSH, and Remote Control needs a Pro, Max, Ultra, Team or Enterprise plan, since API keys don't work with it.

Open what it builds

A dev server that listens on all interfaces opens from your laptop at http://vps:3000, over Tailscale. The Hetzner firewall drops everything from the internet, so the same server stays private even on 0.0.0.0. Docker publishes container ports on 127.0.0.1 only, and to reach one from your laptop publish it on the server's Tailscale IP (-p 100.x.y.z:3000:3000). For a site you want public, pass a CLOUDFLARE_TUNNEL_TOKEN and add a route to http://127.0.0.1:3000 in the Cloudflare dashboard.

Doing it by hand

Follow how to lock down a Hetzner VPS by hand, add a non-root user, and as that user run:

curl -fsSL https://claude.ai/install.sh | bash

Then, as root, let bubblewrap use user namespaces so the sandbox works:

cat > /etc/apparmor.d/bwrap <<'END'
abi <abi/4.0>,
include <tunables/global>
profile bwrap /usr/bin/bwrap flags=(unconfined) {
  userns,
  include if exists <local/bwrap>
}
END
systemctl reload apparmor
