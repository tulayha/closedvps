Codex on a Hetzner VPS, with every port closed

On a VPS, OpenAI's Codex CLI keeps working while your laptop sleeps. It also runs the code it writes, starts dev servers and installs packages, so the server it runs on should have nothing reachable from the internet. ClosedVPS buys that server with one command and installs Codex on it.

Pick a server

Codex asks for 4 GB of RAM at least and recommends 8 GB. On Hetzner that's a CX23 or the ARM CAX11 at 4 GB, or a CX33 at 8 GB (current prices). The cheap types are often sold out, and what to do when Hetzner is sold out covers that.

Create it with Codex on it

closedvps create --codex --type cx33,cx23,cax11

It buys the first of those that's in stock, behind a Hetzner firewall with no inbound rules, and the server joins your tailnet on its first boot. You get a user named after your account on your computer, with your SSH key, and Codex installed for that user. Codex sandboxes its commands with bubblewrap, which can't create the user namespace it needs on Ubuntu 24.04 without an AppArmor profile, so ClosedVPS installs bubblewrap and adds that profile. Add --claude to put Claude Code on the same server.

Log in

First turn on device code login in your ChatGPT security settings. Then:

ssh dev@vps
codex login --device-auth

Open the link it prints in your laptop's browser, sign in, and enter the one-time code (OpenAI's docs on headless login). Then run codex inside tmux, so it keeps going after you close SSH.

Open what it builds

A dev server that listens on all interfaces opens from your laptop at http://vps:3000, over Tailscale, while the Hetzner firewall drops everything from the internet. To keep the server from reaching your laptop in return, give it the tag in Tailscale for a VPS.

Doing it by hand

Follow how to lock down a Hetzner VPS by hand, add a non-root user, and give bubblewrap its AppArmor profile as in the Claude Code steps, with apt install bubblewrap. Then, as that user:

curl -fsSL https://chatgpt.com/codex/install.sh | sh
