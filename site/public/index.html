A free CLI for Hetzner Cloud

A Hetzner server with every port closed.

ClosedVPS buys it from your own computer. When Hetzner is sold out, it checks every minute and buys the first server on your list that comes into stock, up to the price you set. You get in over Tailscale.

What you get

Locked down before it boots.

On every server

No inbound rules

A Hetzner firewall that lets nothing in, attached before the first boot. closedvps list warns if another firewall opens it.

from your laptop
$ nmap -Pn 203.0.113.1Not shown: 1000 filtered tcp ports
SSH over Tailscale only

Key login for your user. Root and passwords can't log in.

the server's SSH settings
PermitRootLogin noPasswordAuthentication no
Security updates daily

With a reboot at 04:00 UTC when one needs it.

/etc/apt/apt.conf.d/52closedvps
Unattended-Upgrade::Automatic-Reboot "true";Unattended-Upgrade::Automatic-Reboot-Time "04:00";
Docker stays private

Published ports bind to 127.0.0.1, so a container can't open one by accident.

/etc/docker/daemon.json
{ "ip": "127.0.0.1" }

Before you start

The first run asks the rest and remembers it. closedvps create --dry-run shows the whole setup before you pay, and the README lists every option.

  • A Hetzner API tokenRead & Write, from your project in the Hetzner Console.How to make one
  • TailscaleRunning on this computer. Each run asks for a one-off auth key.DownloadMake a key
  • An SSH keyFound on this computer. No key yet? ssh-keygen -t ed25519

If Tailscale stops working

Open port 22 to your own IP, fix Tailscale over SSH, then close it again.

$ closedvps open-ssh vps
$ ssh dev@203.0.113.1
$ closedvps close-ssh vps
